# Archived release audits

These are point-in-time audit notes written while HoneyLens was being prepared for its first public
release (October 2026). They are kept for transparency, but they are **historical**: some statements
in them (for example "CI not yet verified" or "no commits yet") were true when written and were
later superseded. For the current state, see the main [README](../../README.md) and the latest CI run.
