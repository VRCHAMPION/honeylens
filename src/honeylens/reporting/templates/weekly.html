8. Methodology and limitations

  • Data: Cowrie {{ cowrie_version }} SSH honeypot JSON logs, parsed by the HoneyLens pipeline into PostgreSQL. Times stored in UTC, shown in IST.
  • ATT&CK mapping: {{ rule_count }} regex rules against Enterprise ATT&CK v{{ attack_version }}. A regex match is evidence, not proof; obfuscated commands can be missed (false negatives) and harmless text can match (false positives).
  • Severity (0-100) and classes are transparent heuristics; each session stores the reasons for its score. Bot-vs-human uses command timing and needs at least 3 commands.
  • GeoIP/ASN: offline MMDB databases if installed; simulator IPs get deterministic demo values (private-use ASNs 64512+). Registration location is not attacker identity. If DB-IP Lite is configured, attribution is “IP Geolocation by DB-IP” (CC BY 4.0); other database providers have their own terms.
  • A honeypot only sees attackers who chose to connect to it. It does not measure attacks against other systems.
  • Week-over-week compares {{ days }}-day windows; small numbers swing a lot in percentage.
